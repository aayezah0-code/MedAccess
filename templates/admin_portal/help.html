Help & Operational Knowledge Base

Standard operating procedures, verification protocols, security policies, and technical support references for MedAccess administrators.

Pharmacy Verification Protocol

Every partner pharmacy must be verified against state drug regulatory records before gaining access to patient prescription fulfillment:

  • Verify drug license number matches the registered state jurisdiction.
  • Ensure GSTIN format adheres to Indian GST structure (15 alphanumeric characters).
  • If rejected, provide specific corrective feedback so the pharmacy can update and resubmit.

Patient Account Management

Policies governing patient account provisioning, deactivation, and medical record retention:

  • Administrative provisioning creates verified accounts with immediate access.
  • Deleting accounts with linked medical records automatically safely deactivates them.
  • Deactivated accounts are immediately blocked from logging in.

Two-Admin Security Model

The platform enforces a strict predefined administrative identity whitelist:

  • Only authorized email identities can access the custom Admin Portal.
  • Unlisted staff, superusers, or altered roles receive HTTP 403 Forbidden.
  • Public registration forms reject any attempt to use predefined admin emails.

Frequently Asked Administrative Questions

Q: Can a rejected pharmacy appeal or correct their details?

Yes. When a rejected pharmacy logs in, they are redirected to a secure resubmission portal where they can view the rejection feedback, correct license or store information, and resubmit for verification. Their status returns to PENDING upon submission.

Q: Why are medicines stock counts separated by unit instead of summed together?

Healthcare inventory items are packaged in fundamentally incompatible units (e.g. Tablets, Bottles, Strips, Vials). Summing 100 Tablets with 2 Bottles yields an invalid number (102). MedAccess groups inventory quantities strictly by unit to ensure clinical and audit accuracy.

Q: What should I do if an admin password needs to be rotated?

Admins can reset their password via the standard secure password reset workflow or run the management command python manage.py provision_admins --reset-passwords in a secure shell.
